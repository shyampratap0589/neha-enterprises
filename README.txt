NEHA ENTERPRISES WEBSITE
========================

Files:
- index.html: website structure
- style.css: responsive premium navy/blue styling
- script.js: product catalogue, filters, cart and WhatsApp order flow

Preview:
Open index.html in a web browser. Internet is needed for the Google font and product photos.

Important:
- This is a static website. The cart sends the selected items to WhatsApp for order confirmation.
- It does not take online card/UPI payments or manage inventory automatically.
- Product price ranges are indicative placeholders. Confirm actual prices, model numbers, stock, tax and delivery before publishing.
- Brand availability should be confirmed with Neha Enterprises before advertising specific models.
- Update phone/email/address in index.html if needed.

Publish on GitHub Pages:
1. Create a public repository on GitHub.
2. Upload index.html, style.css, script.js and README.txt to the repository root.
3. Open repository Settings -> Pages.
4. Under Build and deployment, select Deploy from a branch, choose main and /(root), then Save.
5. Wait for GitHub Pages to publish and use the Visit site link.
Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages
