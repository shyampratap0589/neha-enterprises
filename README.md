## 🌐 How to Make Your Website Live on GitHub Pages (Free & Official)

To publish your website on GitHub and get a live public link (e.g. `https://<username>.github.io/neha-enterprises/`):

### Method A: Upload Directly via GitHub Web (No Command Line Needed - Takes 2 Minutes)
1. Log into your GitHub account at **[github.com](https://github.com/)**.
2. Click the **"+"** button at the top-right corner and choose **"New repository"**.
3. Name your repository: `neha-enterprises` (or any name you like).
4. Set it to **Public**, check **"Add a README file"**, and click **"Create repository"**.
5. On the new repository page, click the **"Add file"** button and choose **"Upload files"**.
6. Open your folder `C:\Neha Enterprises` in Windows File Explorer.
7. Select and drag all your files and folders:
   - `index.html`
   - `css/` (folder)
   - `js/` (folder)
   - `images/` (folder)
   - `README.md`
8. Drop them into the GitHub page and click the green **"Commit changes"** button.
9. Go to **Settings** (tab on top) -> **Pages** (in the left navigation menu).
10. Under **Branch**, select `main` (or `root`) and click **Save**.
11. In 1 to 2 minutes, GitHub will show you your live link:
    **`https://<your-username>.github.io/neha-enterprises/`** 🎉
